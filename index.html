How it works

A simple sequence, checked again every time the handheld is idle.

Idle with the screen off

After the screen has been off for a set time, HeyFolks! starts checking the environment.

Light check

If the ambient light stays below the threshold for several readings in a row, the device is probably inside a pallet sleeve or a closed place.

Search for neighbors

The app looks for another HeyFolks! device nearby by Bluetooth Low Energy and/or sound, for a set search window.

Alarm or silence

If a neighbor is found, the device waits and searches again. If none is found, the alarm sounds with vibration until the operator picks the device up.

Who benefits most

Logistics operations and 3PLs

Warehouses, distribution centers, cross-docking hubs and third-party logistics (3PL) operations move handhelds through picking, put-away, receiving, dock, yard and returns (reverse logistics). A device left in a pallet sleeve, a returns cage or a dock lane means lost productivity, inventory discrepancies and SLA breaches. HeyFolks! sounds an alarm when a handheld sits idle at those points, so it is found before it causes a discrepancy, an SLA breach or a shipping mistake.

Features

Everything the app does, and the settings you can change on each device.

Core

Dark detection with the screen off

Reads the ambient light sensor and triggers the search when the light falls below the threshold for a set number of readings. Threshold, reading interval and screen-off time are all configurable.

Core

Neighbor detection by Bluetooth (BLE)

Each device advertises an identifier and looks for the others. You set the signal strength (dBm) that counts as nearby, how long a sighting stays valid, the scan mode and the advertising power. A live list shows which devices are seen as neighbors.

Prototype

Neighbor detection by sound

As an alternative to Bluetooth, each device plays a short tone sequence and listens for others at a configurable frequency and volume.

Core

Screen on, but no movement

Detects a handheld that stays with the screen on, dark and without movement for a set number of minutes. The accelerometer defines what counts as still. Movement stops this alarm.

Optional

Fall detection

Uses the accelerometer to detect a fall (free fall followed by impact, or impact only). The threshold can be calibrated with a simulated fall. Optionally, the alarm can only be stopped with a PIN.

Core

Devices without a light sensor

If the device has no light sensor, the app says so and uses only the idle time with the screen locked as the trigger. The time is configurable, so long idle periods can be allowed.

Core

Alarm sounds and vibration

Pick one or more alarm sounds, or add your own audio files. The alarm can sound at maximum volume and vibrate, and you can turn the sound off and keep only the vibration.

Core

Permissions check

A permissions screen shows what is OK and what is missing: battery optimization, Bluetooth, location for BLE, microphone, notifications and the light sensor. It also shows live charts for light, microphone and movement, with minimum, maximum and average values.

Core

Event log

Every event is recorded in a CSV file on the device: alarms, searches, neighbors found, screen changes and status. You can view a summary in the app and share the file. The file is capped at 50 MB; when it is full, the oldest lines are removed.

Core

Three languages

The app is available in English, Portuguese and Spanish, and the language can be changed in the settings.

This is a version under testing. Test it on your own devices before relying on it, and confirm that the alarm, sound and neighbor detection work as expected in your environment.

Security

What the Bluetooth signal does, and what it does not do.

Broadcast only, no connection

HeyFolks! only broadcasts a Bluetooth Low Energy (BLE) advertising signal, which other devices running the app can read. The signal does not open a connection, does not ask for a password and gives no access to the device.

No personal data in the signal

The signal carries only a random numeric code generated by the app. It contains no name, phone number, account, location or content from the device.

No hacking or remote access

Bluetooth in HeyFolks! cannot read files, messages, photos, passwords or the camera, and cannot control the device. The app uses only what the alarm needs: the light sensor, Bluetooth to detect nearby devices and, if you enable them, the sound and motion sensors.

Requirements

  • Android 8.0 (Oreo) or later.
  • Bluetooth Low Energy for neighbor detection by BLE.
  • A light sensor for dark detection. Without one, the app uses the idle-time trigger.
  • Permissions for Bluetooth (or location on Android 8 to 11), microphone for sound detection, and notifications. The app asks for each one when needed.
  • Battery optimization turned off for the app, so the monitoring keeps running in the background.

Your data

  • The event log and settings are stored on the device.
  • The app does not record keyboard input or take screenshots.
  • You can clear the settings at any time with "Restore app defaults" on the About screen.
